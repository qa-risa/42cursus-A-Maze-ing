# A-Maze-ing

## Description
### 概要
A-Maze-ingは42cursusのMilestone2のペア課題です。迷路生成、最短経路の導出、ビジュアライズをするのが主な内容をなっています。
迷路生成について、採用したアルゴリズムは**Prims**, **Kruskal**, **recursive backtracker**です。これらの実装を通して迷路生成アルゴリズムの基礎を学べます。迷路の中心には42の文字を表示させます。完全迷路と、Pαc -Manで使用可能な不完全迷路の切り替えをできるようにします。
最短経路の導出について、**幅優先探索(Breadth First Search)**を採用しています。木構造の探索方法を学ぶことができます。
ビジュアライズについて、選択制となっており、**Ascii Rendering**あるいは**Minilibx**を使用します。今回は**Ascii Rendering**を採用しました。ターミナルにおけるビジュアライズの基礎が学べます。
### 詳細
#### Mandatory(必須パート)
1. config.txtで迷路の詳細を指定できるようにする。conifg.txtにはKEY=VALUEの形式でwidth, heightなどの情報を記載する。config.txtの内容はUsageを参照。
2. 迷路はランダムに生成されます。SEEDによって再現性を持つ必要があります。
3. それぞれのセルは東西南北に0~4個の壁を持ちます。
4. EntryとExitは異なること。全てのセルは到達可能であること。EntryとExitは迷路内に
5. 3 * 3以上のオープンスペースを持たないこと。2 * 3はOK。
6. ビジュアライズの際に、閉じたセルで42が書かれていること。
7. PERFECTフラグがTrueの時は、任意の二点間の経路は1つであること
8. PERFECtフラグがFalseの時は以下のようなPac-Manで使用可能な迷路を作成すること.
    -全てのセルは到達可能であること。
    -4隅と中央のセルはひらけていること.
    -任意の２点間の経路は少なくとも2つあること.
    -dead-endsはレアであること。１つもないのが推奨される。
9. 迷路のサイズが小さく、42が迷路内に組み込めない場合はエラーメッセージを出力すること
10. 迷路を出力するファイルのルールは以下のようにすること。
    -各セルには16進数が割り当てられていること。Bitで0(LSB)がNorth, 1がEast, 2がSouth, 3がWestの壁の有無を表すこと。1なら壁があり、0なら壁がない。
    -例えば、0011は、southとwestが開いている。1010は、eastとwestに壁がある。
    -このルールに則った迷路を出力すること
    -空行の後に、Entry, Exitの座標、最短経路を表す方角の文字列を出力すること。
11. ASCII renderingによって迷路をビジュアライズすること。少なくとも以下の選択肢は含めること。
    -迷路の際生成
    -最短経路の表示/非表示
    -迷路の壁の色の変更
12. .whlファイルにパッケージ化すること

#### Bonus(ボーナスパート)
1. dead-endの数を0にすること
2. 2つの迷路生成アルゴリズムに対応すること
3. 迷路生成のアニメーションを表示させれるようにすること

#### Extra(課題要件を超えた内容)
1. dead-endの最大数を指定できるように
2. 3つの迷路生成アルゴリズムに対応。
3. BFSのアニメーションを表示させれるように

### 設定ファイル(config.txt)の形式
- 1行に1つ、`KEY=VALUE`の形式で書きます。`=`の前後の空白は無視します。
- `#`で始まる行と空行は無視します(コメント)。
- キーは小文字でも構いません(`width=20`も可)。
- 同じキーを2回書く、`=`がない行がある、必須キーがない、値の形式が違う場合は、エラーメッセージを表示して終了します。

## Algorithm
課題の主要部分のみ抜粋して解説します。細かい部分はコードを見てください。
### 迷路生成
**Prim**, **Kruskal**, **recursion**(再帰的バックトラック)の3つのアルゴリズムを採用しました。デフォルトはrecursionです。

選んだ理由は以下です。
1. 3つとも課題で代表例として挙げられており、資料が多い。
2. 3つとも「全域木」を作るので、生成直後は必ず完全迷路になる。PERFECT=Trueの条件を自然に満たせる。
3. 42のセルを「最初から訪問済み」にしておくだけで、42を避けて迷路を作れる。
4. 見た目の特徴が違う。recursionは長い一本道が多く、Primは短い枝分かれが多く、Kruskalはその中間になる。アニメーションで違いを比べられる。
アニメーションを表示させると各アルゴリズムへの理解が深まると思うので、ぜひ活用してください。
まずは、**Prim**, **Kruskal**. **recursion**それぞれのアルゴリズムで迷路を生成します。これによって生成された迷路は木構造になり、任意の二点間の経路は１つしかない完全迷路になります。この時、中心に42の文字を作成できるように、42に該当する部分は壁を破壊できないようにします。
次にこの完全迷路を元に不完全迷路を作成します。
各アルゴリズムの具体的な解説は以下です。
#### Prim
1. 42以外のセルを1つランダムに選び、訪問済みにする。
2. 訪問済みのセルと未訪問のセルの間の壁を、候補リスト(frontier)に入れる。
3. 候補リストからランダムに1つ取り出す。先のセルが未訪問なら、その壁を壊して訪問済みにし、そのセルの周りの壁を候補に追加する。
4. 候補リストが空になるまで3を繰り返す。

#### Kruskal
1. 42以外の、隣り合うセルの間の壁をすべてリストにして、順番をシャッフルする。
2. 最初は、すべてのセルを別々のグループとする(Union-Find)。
3. 壁を順番に見て、両側のセルが別のグループなら、壁を壊して1つのグループにする。同じグループなら壊さない(壊すとループができるため)。
4. 全部の壁を見たら終了。

#### recursion
再帰的なバックトラックを採用。以下のようなアルゴリズムで動作しています。
1. 全てのセルの四方を壁にする。
2. ランダムで任意のセルを選択。そのセルを訪問済みにする。
3. セルの四方のうち、壁がある方角かつその方角の隣のセルが訪問済みでない方角の壁を壊し、道に変更する。
4. 壊した方角のセルに移動。
5. 3, 4を現在のセルの四方のうち、壁がある方角かつその方角の隣のセルが訪問済みでない方角が無くなるまで繰り返す。
6. 一つ前のセルに戻る。
7. そのセルの四方のうち、壁がある方角かつその方角の隣のセルが訪問済みでない方角がああれば破壊して、壊した方角のセルに移動する。なければ、6に戻る。

以上のように、進めるところまで進んで、進めなくなれば進めるようになるところまで戻り、また進めるところまで進むのを繰り返して全てのセルが訪問済みになるまで繰り返すのがバックトラックによる迷路生成アルゴリズムです。進めるところまで深さ優先で進むアルゴリズムです。

#### 完全迷路から不完全迷路に
以上のアルゴリズムで作成された迷路は、任意の二点間の経路が１つしかない完全迷路になります。
今回の課題では、config.txtでPERFECT=Trueで指定すると完全迷路になり、PERFECT=Falseで指定すると不完全迷路になるように指示されています。
不完全迷路とは、このプロジェクト内では以下のように定義します。Pac-Manで使う迷路をイメージしてください。
1. 全てのセルに到達できること
2. 四隅と中心は開けていること
3. 任意の二点間の経路は少なくとも２つあること
4. dead-endの最大数を指定できること(ボーナス)

４について、config.txtに以下を書くことで、dead-endの最大数を指定できる(省略時は0)。
```
MAX_DEAD_ENDS=0
```
以上のような不完全迷路を作成するために、完全迷路を作成してからそれを改変し、不完全迷路にする手法を取りました。完全迷路に対して以下の操作を行うことでそれぞれの項目を満たした不完全迷路に改変されます。
1. 完全迷路は木構造になっているので、元から全てのセルの到達できるので何もしなくてもこの条件は満たせます。
2. 四隅は迷路の外周以外の壁を破壊します。中心は全ての壁を破壊します。
3. 少なくとも１つの壁を壊すと、ループが少なくとも１つできるので、任意の二点間の経路は少なくとも２つになります。
4. dead-endになるセル（４方角のうち３つが壁になっているセル）のうち、max-dead-endsで指定した数（dead-endになるセルの数がmax-dead-endより小さければそのセルの数）を選択し、その壁以外で、壁がある方角からランダムに一つを選び破壊する。

### 最短経路の導出
経路探索の代表的な手法には**幅優先探索**, **深さ優先探索**の2種類があります。前述の通り、迷路は木構造になっています。以下の画像のような木構造を元に解説します。(画像はAIで生成)
![image.png](screenshots/tree_construction.png)
幅優先探索は、Aをスタートすると、A,B,E,C,D,,F,Gの順番に探索しゴールを探していきます。
深さ優先探索は、Aをスタートとすると、A,B,D,E,C,F,Gの順番に探索しゴールを探していきます。
どちらのアルゴリズムを採用して最短経路を求めても構いませんが、今回は幅優先探索を選択しました。早いからです。早い理由は以下の解説を読めばわかります。それぞれのアルゴリズムを選択した場合にどのように実装すればいいのかを以下で解説します。
#### 幅優先探索(BFS)
探索をしながらゴールを見つけた場合、スタートからゴールまで辿るとそれ自体が最短経路になるので、スタートからの各ノードへのそれぞれの経路を記憶しておき、ゴールを見つけると、ゴールとスタートのノードを繋ぐ経路がそのまま最短経路になります。
#### 深さ優先探索(DFS)
スタートから開始し、幅優先でゴールを探索します。各ノードへの経路を保存しておきます。ゴールを見つけると、ゴールとスタートを結ぶ経路が最短経路です。というようにしてはいけません。深さ優先探索は深さ優先でとりあえず一つでも経路を見つければ終了してくれるので、場合によっては幅優先より早く経路を求めてくれるというメリットはある一方で、必ずしもそれが最短経路とは限りません。１工夫しなければなりません。工夫の１つの案としては、DFSで進める深さの限界値を決めておくことです。最初は限界値を1に設定します。限界値が1の探索でゴールに辿り着けなければ限界値を2にして再度探索します。このようにDFSの限界値を1ずつ増加させて探索していけば最初にゴールを見つけたとき、それは最短経路になります。BFSと比較すると、DFSの方が早いことも確かにあり得ますが、全体的に見るとこの方法では何回もBFSを行わないといけないので、基本的にはBFSの方が早そうです。というかこれって結局BFSとやってること同じで無駄に操作増えてるだけですしね。

### 迷路生成, BFSアニメーション
迷路生成及びBFSのアニメーションを実装した。
#### 迷路生成アニメーション
Structureのクラス構造を参照してください。迷路生成アルゴリズムは、全てMazeGeneratorBasicクラスを継承しています。MazeGeneratorBasicクラスには、迷路生成に関する基本的なメソッドや、完全迷路を不完全迷路に変換するメソッドなどが含まれています。そのうちの一つに、break_wallメソッドがあります。これは、指定した座標のセルの指定した方角の壁を破壊するメソッドです。迷路生成の際は、最初は全て壁になっており、壁をbreak_wallメソッドで破壊して迷路を作成していきます。
そのため、break_wallメソッドを呼び出す際に使用したセルの座標をhistoryとして記憶しておきます。これをビジュアライズの際に壁を壊し、迷路を表示し、0.03秒停止し、もう一度次の壁を壊し、表示し、0.03秒待機するというのを繰り返せす、0.03秒に1フレーム更新されるパラパラ漫画のような形式のアニメーションとして実装しました。
#### BFSアニメーション
最短経路をを求める際のBFSの挙動がよくわかるような実装にしました。ただ単に最短経路を辿るアニメーションをつけるだけではつまらないので。迷路生成アニメーション時と同様に、BFSで最短経路を求める際に訪問したセルの順番をhistory_bfsとして記憶しておきます。ビジュアライズの際に、この順番で訪れたセルの色を変える、迷路を表示する、0.02秒待機する。次に訪れたセルの色を変える、迷路を表示する、0.02秒待機する。を繰り返すと徐々にスタートからゴールに向かって色が変わっていって、ゴールに辿り着いた時に改めて最短経路を表示するという実装にしました。

基本の使い方(インスタンス化・パラメータ指定・構造と解へのアクセス):
```python
import random
from mazegen import Config, MazeGenerator
from mazegen.bfs import BreadthFirstSearch

# 1. パラメータを指定して設定を作る(サイズ、シードなど)
config = Config(
    WIDTH=20,
    HEIGHT=15,
    ENTRY=(0, 0),
    EXIT=(19, 14),
    OUTPUT_FILE="maze.txt",
    PERFECT=True,
    SEED=7,
)

# 2. シードを設定して、迷路を生成する
random.seed(config.SEED)
maze = MazeGenerator(config)  # MazeGeneratorPrims, MazeGeneratorKruskals も同じ使い方
maze.maze_gen()

# 3. 生成した構造にアクセスする
#    maze._pos[x][y].value が壁の情報(N=8, E=4, S=2, W=1 のビット)
#    ※出力ファイルとはビットの並びが違う(出力時に変換している)
maze.maze_show()  # 16進数で表示
cell = maze._pos[0][0]
print(cell.value, cell.is_42)

# 4. 解(最短経路)にアクセスする
bfs = BreadthFirstSearch(maze._pos, maze._config)
bfs.search_maze()
print(bfs._path)          # [(0, 0), (0, 1), ...] 座標のリスト
print(bfs._path_cardinal) # "SSE..." 方角の文字列

# 5. 課題の形式でファイルに書き出す
maze.output_to_file(bfs._path_cardinal)
```
